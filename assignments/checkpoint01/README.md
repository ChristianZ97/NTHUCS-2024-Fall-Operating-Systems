# Cooperative Multithreading

Build with SDCC from this directory:

```sh
make
```

Load `testcoop.hex` in EdSim51 to inspect execution. The original Makefile is recovered from `Source Code.zip`; canonical C/header files come from the actual submission. Simulator execution has not been verified in this curation.
